# TAHOPE_data_process
本篇記錄為處理TAHOPE相關IOP/SOP時，有關地面測站、觀測資料(任意)的問題與細節，僅供參考，有可能有本人沒有遇過的問題。

## 地面測站
地面測站包含{date}.QPESUMS_STATION.15M的自動站資料，以及{date}.QPESUMS_STATION.10M的有人站資料，自動站分布較多且廣，但山區都比較少，如果想要使用到山區的測站資料，要斟酌使用。
由於有上面兩種資料，資料處理上有幾點需要注意：
<p>1. 所有資料、變數名稱所顯示的<strong>時間都是UTC</strong></p>
<p>2. 資料內變數名稱兩者差異不大，但是風向風速這類變數，在有人站是有瞬時跟平均兩個種類，所以變數的名稱不太一樣，其中下圖中的變數名稱分別在10M和15M是對應的</p>

<p>3. 如果你是在ASRAD上下載每小時資料的話，會有一些固定的QC數值
      * -9991:儀器故障待修
      * -9996:資料累計於後
      * -9997:因不明原因或故障而無資料
      * -9998:雨跡(Trace)
      * -9999:未觀測而無資料
